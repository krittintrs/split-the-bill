# Peer access is capability-URL; login is optional and only adds tracking

Peers interact with a Bill purely by holding its unguessable link — tick anything, toggle any Paid Flag, no account (matches how the group's shared Google Sheet worked). Google login for peers exists but is strictly additive: an Account Claim links their account to an organizer's Peer record and unlocks My Debts. No peer-facing action ever requires login.

**Considered options:** required peer login (cleaner attribution, but OAuth friction inside LINE's in-app browser risks the group reverting to the sheet), strict claim-your-name (blocks the common "one person ticks shared water for everyone" flow). The free-for-all is deliberate; do not "fix" it by adding permission checks to peer actions.
